# Kids Player — app "Pokémon" para TV Samsung (Tizen)

App privado para TV Samsung com catálogo curado de vídeos do YouTube (1ª geração de Pokémon, 112 episódios),
isolado do resto do YouTube e navegável pelo controle por uma criança que ainda não lê.

**Projeto encerrado** (o player embutido do YouTube não toca a dublagem pt-BR). Tudo o que foi aprendido
está em **[knowledge/](knowledge/README.md)** — comece por lá para fazer um novo app de TV.

| Pasta | O que é |
|---|---|
| `KidsPlayer/` | Projeto Tizen (casca) criado pela extensão Tizen do VS Code |
| `docs/` | App real publicado no GitHub Pages (catálogo + player + `episodes.json`) |
| `tools/` | `gerar_catalogo.py` — gera o catálogo a partir de uma playlist |
| `knowledge/` | Base de conhecimento: ambiente, arquitetura, limites do YouTube, problemas e checklist |
| `tizen/`, `docs/player.html` | Legado do Hello World |
